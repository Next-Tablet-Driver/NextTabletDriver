# SDK

This folder has everything for developers who want to build on NextTabletDriver. It has two separate kits:

| Kit | For | Where |
| --- | --- | --- |
| **Plugin API** (`ntd_plugin_api`) | Writing a **plugin**: a small library that NextTabletDriver loads to change pen data, for example to smooth the pen path. | [`plugin_api/`](plugin_api), with the examples [`examples/rust_plugin`](examples/rust_plugin) and [`examples/c_plugin`](examples/c_plugin). |
| **Embedding SDK** (`ntd_sdk`) | Putting the tablet engine **inside your own program**, such as a game or a tool, so that you can read the pen without the desktop app. | The files in this folder, with the headers in [`include/`](include), the C# wrapper in [`bindings/csharp`](bindings/csharp), and the examples [`examples/c_consumer`](examples/c_consumer) and [`examples/csharp_console`](examples/csharp_console). |

They are different things. A plugin runs *inside* NextTabletDriver. The embedding SDK runs NextTabletDriver's engine *inside you*.

## I want to write a plugin

1. Read the [Plugin development guide](../docs/plugin-development.md).
2. Copy [`examples/rust_plugin`](examples/rust_plugin) (Rust) or [`examples/c_plugin`](examples/c_plugin) (C), and change it.

## I want to read the pen in my own program

1. Read the SDK part of [Integrations](../docs/integrations.md#sdk).
2. Build the library and run an example:

   ```bash
   cargo build --release --manifest-path sdk/Cargo.toml
   ```

   Then follow the README of [`examples/c_consumer`](examples/c_consumer/README.md) or [`examples/csharp_console`](examples/csharp_console/README.md).

If you only need live pen data for a web page or a stream overlay, the [WebSocket server](../docs/integrations.md#websocket) is simpler.

## Folders

| Path | What it is |
| --- | --- |
| `plugin_api/` | The `ntd_plugin_api` crate: the plugin interface and the macro that exports it. |
| `src/` | The `ntd_sdk` library: the C interface (`ffi.rs`), the engine loop, logging. |
| `include/ntd_sdk.h` | The C header of the embedding SDK. Generated by the build. Do not edit it by hand. |
| `bindings/csharp/` | The C# wrapper (`NtdClient`) and the generated `NativeMethods.g.cs`. |
| `examples/` | Four small programs: two plugins and two SDK consumers. |
| `build.rs`, `cbindgen.toml` | Generate the C header and the C# declarations. |

The embedding SDK has its own version (see `Cargo.toml`) and its own interface version (`NTD_SDK_ABI_VERSION`). The plugin API has another interface version (`NTD_PLUGIN_ABI_VERSION`). They do not depend on each other.
