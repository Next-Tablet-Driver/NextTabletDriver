# frontend-react

The React 19 rewrite of the interface, with the design of the Svelte `frontend/` copied 1:1. It
grows beside the Svelte `frontend/` until the switch; see [`docs/frontend-react.md`](../docs/frontend-react.md) for the
plan, the sub-tasks and where the old frontend is kept.

```bash
npm install
npm run dev            # Vite dev server
npm run check          # tsc
npm run lint
npm run format:check
npm run test -- --run
```
